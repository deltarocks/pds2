= Lexical
:order: 1

PDS is a declarative IDL for describing binary protocols. A source file is a
sequence of statements; each statement is a chain of values terminated with `;`.

== Identifiers

[source]
----
[a-zA-Z_][a-zA-Z_0-9]*
----

== Numbers

Decimal (`42`, `-1`), hexadecimal (`0x2a`) or floating point (`-1.5`, `1e300`).

== Strings

Single-line: `"text"` (escapes `\n`, `\r`, `\t`, `\0`, `\\`, `\"`, `\u{HEX}`; no raw newline).
Bytes: `b"\x12\x02ok"` (escapes `\xNN`, `\n`, `\r`, `\t`, `\0`, `\\`, `\"`).
Block:

[source]
----
"""
multi
line
"""
----

== Comments

There are no comment tokens. Use doc attributes (`@!doc "..."`) for human notes.
